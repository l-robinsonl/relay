# Icons

These are **placeholder** icons, generated by a script in the initial commit so
the application builds and has something recognisable in a dock.

Before release, replace them with real artwork:

```sh
npm run tauri icon path/to/icon.png   # 1024×1024 source, square, transparent
```

That regenerates every size, including the `.icns` and `.ico` bundles macOS and
Windows installers need, which are not committed here.
